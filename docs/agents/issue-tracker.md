# Issue Tracker

This repo uses GitHub Issues for external issue tracking.

- Repository remote: `git@github.com:chengjon/TdxQuant.git`
- Preferred CLI: `gh`
- Default issue target: the GitHub repository behind `origin`

If GitHub authentication is unavailable in an execution environment, agents may draft issue text locally and report the intended `gh issue create` command, but should not invent a second permanent issue store unless the maintainer explicitly changes this file.
