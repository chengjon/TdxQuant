# Triage Labels

Matt Pocock skills should use the default triage role labels for this repository.

| Role | Label |
| --- | --- |
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Fully specified and ready for an agent | `ready-for-agent` |
| Needs human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

Do not create alternate labels for the same roles unless this file is updated first.
