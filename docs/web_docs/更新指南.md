# TdxQuant 在线文档提取指南

目标站点：`https://help.tdx.com.cn/quant/docs/markdown/`

## 站点技术背景

- 基于 **VuePress 1.8.2** 构建的 SPA 站点
- 页面采用 SSR（服务端渲染），HTML 中直接包含完整正文内容，无需浏览器渲染
- 目录列表（`/docs/markdown/`）返回 403，无法直接遍历
- 无 `sitemap.xml`
- 所有页面路由定义在主 JS bundle 中

## 提取流程

### 第一步：获取 JS bundle 中的完整路由表

站点所有页面路由都硬编码在 VuePress 的主 JS 文件中。先从页面 HTML 中找到当前 JS bundle 文件名：

```bash
curl -s 'https://help.tdx.com.cn/quant/docs/markdown/Dict.html' | \
  grep -oP '/quant/assets/js/app\.[a-f0-9]+\.js' | head -1
```

输出示例：`/quant/assets/js/app.effacf9c.js`

> **注意**：每次站点重新构建部署后，文件名中的哈希值会变化（如 `effacf9c` → `5069f79c`），必须重新获取。

下载该 JS 文件并提取路由：

```bash
JS_HASH=$(curl -s 'https://help.tdx.com.cn/quant/docs/markdown/Dict.html' | \
  grep -oP 'app\.[a-f0-9]+\.js' | head -1)

TMP_DIR="${TMPDIR:-/tmp}"
curl -s "https://help.tdx.com.cn/quant/assets/js/${JS_HASH}" -o "${TMP_DIR}/tdxquant_app.js"

# 提取 /docs/markdown/ 下的所有路由，去除目录页和 .html 重复项
grep -oP 'path:"(/docs/markdown/[^"]*)"' "${TMP_DIR}/tdxquant_app.js" | \
  sed 's/path://;s/"//g' | \
  grep '^/docs/markdown/' | \
  grep -vE '/$' | \
  grep -vE 'index\.html$' | \
  grep -vE '\.html$' | \
  sort -u > "${TMP_DIR}/tdxquant_content_pages.txt"

wc -l "${TMP_DIR}/tdxquant_content_pages.txt"
```

### 第二步：运行提取脚本

```bash
cd /opt/iflow/TdxQuant
python3 extract_docs.py
```

脚本会自动：
1. 读取系统临时目录中的 `tdxquant_content_pages.txt` 路由缓存（没有缓存时会自动下载 JS bundle 并提取）
2. 逐个抓取每个页面的 `.html` 版本（VuePress SSR 渲染的完整页面）
3. 解析 HTML，提取 `<div class="theme-default-content content__default">` 内的正文
4. 按分类保存到 `docs/web_docs/sections/` 目录
5. 生成合并文件 `docs/web_docs/all_docs.md` 和结构化 JSON `docs/web_docs/docs.json`

### 第三步：检查结果

```bash
# 查看提取统计
ls -lh docs/web_docs/sections/
wc -l docs/web_docs/all_docs.md

# 检查失败页面（通常是分区目录页，无实际内容，可忽略）
grep 'SKIP\|FAIL' 命令输出
```

## 关键注意事项

1. **JS bundle 哈希会变**：站点每次部署后 `app.xxxxxxxx.js` 的哈希值不同，必须从 HTML 中重新获取文件名
2. **路由表可能增减**：文档更新后页面数量可能变化，重新提取路由表即可
3. **两种 URL 格式**：
   - 普通页面：`/quant/docs/markdown/xxx.html`（加 `.html` 后缀）
   - `.md` 结尾页面：`/quant/docs/markdown/xxx/yyy.md`（保持 `.md` 后缀，不加 `.html`）
4. **分区目录页返回 404**：如 `/docs/markdown/mindoc-1ctuhthaq5qmg` 这类路径是导航分组，没有对应 HTML 页面，属正常现象
5. **请求频率**：脚本内含 0.5 秒延迟（每 5 页暂停一次），避免对服务器造成压力

## 如果站点结构发生重大变化

如果 VuePress 升级或站点重构，提取逻辑可能需要调整：

1. 用浏览器开发者工具查看页面结构，确认内容仍在 `class="theme-default-content"` 内
2. 检查 JS bundle 是否仍以 `path:"/docs/markdown/..."` 格式存储路由
3. 如果路由格式变化，修改 `extract_routes_from_js()` 中的正则表达式
4. 如果内容区域 class 名变化，修改 `ContentExtractor` 中的判断逻辑
